# シフトカレンダー

iPhoneのSafariで使うことを想定した、個人用の月間シフト整理アプリです

## 主な機能

- 複数プロジェクトの登録と切り替え
- プロジェクトごとのメンバー登録
- 終日・午前・午後の勤務登録
- 午前は朝日、午後は太陽のモノクロSVG表示
- 左スワイプによるプロジェクト名・メンバー名の編集と削除
- ドラッグによるメンバー表示順の変更
- 勤務入力画面での前日・翌日への移動
- ヘッダーからのバックアップ保存・復元
- カレンダーをタップして設定するプロジェクト別の勤務日
- 共有用カレンダーのPNG画像保存
- 土曜日、日曜日、日本の祝日の色分け
- LINE共有用の月間表示
- JSON形式のバックアップ保存と復元
- ブラウザ内への自動保存

## 使い方

`index.html` をブラウザで開くと動作します

GitHub Pagesで公開する場合は、このフォルダ内のファイルをリポジトリ直下へ置き、Settings → Pagesから公開してください

## データ保存について

入力内容はSafariの `localStorage` に保存され、GitHubへは送信されません

SafariのWebサイトデータを削除した場合や別の端末で開いた場合はデータを引き継げないため、定期的に「保存」ボタンからバックアップしてください

## ファイル構成

- `index.html` 画面構造
- `styles.css` デザインとiPhone向けレイアウト
- `app.js` カレンダー、保存、祝日判定、バックアップ処理
