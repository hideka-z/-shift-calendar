# シフトカレンダー

iPhoneのSafariで使うことを想定した、個人用のシフト整理アプリです

## 主な機能

- 複数プロジェクトの登録と切り替え
- プロジェクトごとのメンバー登録
- 終日・午前・午後の勤務登録
- 午前は朝日、午後は太陽のモノクロSVG表示
- 左スワイプによるプロジェクト名・メンバー名の編集と削除
- ドラッグによるメンバー表示順の変更
- 勤務入力画面での前日・翌日への移動
- 詳細設定からのバックアップ保存・復元
- カレンダーをタップして設定するプロジェクト別の勤務日
- 共有用カレンダーのPNG画像保存
- 土曜日、日曜日、日本の祝日の色分け
- 月をまたいで週が連続する上下スクロール表示
- スクロール位置の上端の週から5週間分をLINE共有用に表示・画像保存
- JSON形式のバックアップ保存と復元
- ブラウザ内への自動保存

## 使い方

`index.html` をブラウザで開くと動作します

GitHub Pagesで公開する場合は、このフォルダ内のファイルをリポジトリ直下へ置き、Settings → Pagesから公開してください

`index.html`ではCSSとJavaScriptに更新番号を付け、iPhoneのSafariに古いファイルが残りにくいようにしています

### スクロールと共有

- カレンダー部分を上下にスクロールして前後の週へ移動できます
- 左右の矢印は前後の月の先頭週へ移動するショートカットです
- 各月の1日は「12/1」のように月も表示します
- 「共有表示」は、上端に一部だけ見えている週も含めて日曜から5週間分を表示します
- 「画像を保存」では、期間・プロジェクト名・更新日・5週間のカレンダーをPNGにします
- 画像ファイル名には期間の開始日と終了日が入ります
- 「共有表示終了」で、元の週とスクロール位置へ戻ります
- 勤務日設定も上下にスクロールでき、メインカレンダーとは独立して移動できます
- 前後の週は必要に応じて読み替え、同時に表示用データを作る範囲を78週間に抑えています

## データ保存について

入力内容はSafariの `localStorage` に保存され、GitHubへは送信されません

SafariのWebサイトデータを削除した場合や別の端末で開いた場合はデータを引き継げないため、定期的に詳細設定の「ダウンロード」からバックアップしてください

## 開発用テスト

実際のSafariの保存内容を使わず、テスト専用データで確認します

```sh
TZ=Asia/Tokyo node tests/continuous-calendar.unit.cjs
```

ブラウザーとPlaywrightを使える環境では、画面操作・画像ダウンロード・表示サイズを確認するテストも実行できます

```sh
TZ=Asia/Tokyo node tests/continuous-calendar.test.cjs
```

ブラウザーテスト用のChromiumのパスは必要に応じて `CHROMIUM_PATH` で指定できます

## ファイル構成

- `index.html` 画面構造
- `styles.css` デザインとiPhone向けレイアウト
- `app.js` カレンダー、保存、祝日判定、バックアップ処理
